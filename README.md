# my-project

## Silkroad phBot Plugin Template

This repository contains a complete base structure for creating Silkroad phBot plugins using Python.

### Files

- **phbot_plugin.py** - Complete plugin template with all required components
- **PLUGIN_GUIDE.md** - Comprehensive guide for using and customizing the plugin

### Quick Start

1. Copy `phbot_plugin.py` and rename it for your plugin
2. Update the plugin information (pName, pVersion, pGuid)
3. Implement your custom logic
4. Place the plugin in phBot's Plugins folder

See [PLUGIN_GUIDE.md](PLUGIN_GUIDE.md) for detailed documentation.
